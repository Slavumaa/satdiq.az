# Satdıq.az

Azərbaycan üçün hazırlanmış müasir elan platforması prototipi. Layihə Avito tipli alqı-satqı təcrübəsindən ilhamlanır, lakin öz brendi, vizual dili və azərbaycanca interfeysi var.

## İmkanlar

- Elanlar üzrə canlı axtarış və şəhər filtri
- Kateqoriya və qiymətə görə sıralama
- LocalStorage ilə seçilmiş elanlar
- Yeni elan yaratma önizləməsi
- Mobil və masaüstü üçün adaptiv dizayn

## İşə salmaq

Statik faylları lokal serverlə açın:

```bash
npx serve dist
```
